# SportsZone — Setup & Run

## Requirements
- [Node.js](https://nodejs.org) — download and install the **LTS** version (free, takes ~2 min)
- A terminal (Command Prompt, PowerShell, or macOS Terminal)

## Steps

**1. Download the project**

Either clone the repo or click **Code → Download ZIP** on GitHub, then unzip it.

**2. Open a terminal in the `software` folder**

- **Windows:** Open File Explorer, navigate into the `software` folder, click the address bar, type `cmd`, press Enter.
- **Mac/Linux:** Right-click the `software` folder → "Open in Terminal" (or `cd` to it).

**3. Install dependencies** (only needed once)

```
npm install
```

**4. Start the server**

```
npm start
```

You should see a startup box printed in the terminal.

**5. Open the app**

Go to **http://localhost:3000** in your browser.

---

Keep the terminal open while using the app — closing it stops the server.  
To stop the server press `Ctrl + C` in the terminal.
